# s_k_y_l_a_r_k_i_n_g ／ 荒腔走板

个人网站：[https://agnesv1.github.io](https://agnesv1.github.io)

笔记（致云雀）、虚构写作（夜莺颂）、摄影（镜花水月），中英双语。

## 技术栈

Astro + GitHub Pages。推送到 `main` 分支后 GitHub Actions 自动构建部署，约 1–2 分钟生效。
内容是 `src/content/` 下的 Markdown；设计变量集中在 `src/styles/global.css` 顶部。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # 构建检查
```

需要 Node 22.12+。
